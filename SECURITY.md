# Security

## Reporting a vulnerability

Please **do not** open a public GitHub issue for security reports.

If you believe you have found a security vulnerability in TracesHub, contact
the maintainers privately with enough detail to reproduce and assess the issue
(including affected component, version or commit, and impact). We will
acknowledge receipt and work with you on a coordinated disclosure timeline.

## Scope

Reports should cover this repository and the hosted TracesHub product
(`traceshub.com` / `api.traceshub.com`) when operated by the maintainers. Issues
in third-party dependencies may be forwarded upstream as appropriate.

## Supported versions

Security fixes are applied to the active development branch and released or
deployed according to maintainer policy. There is no long-term LTS guarantee
during the greenfield phase; check the implementation plan and release notes
when they exist.
